0 Backend session layer (prerequisite)

BACKENDnone — do first §4.2
Let the engine answer against an arbitrary user-opened workbook via a session, instead of the hardcoded company→file map. This unblocks Sheet, Ask AI, and Dashboard.
Tasks
  • In-memory session registry {session_id: FinancialFactStore} (uuid keys).
  • POST /api/fie/sessions (multipart .xlsx) → ingest once via from_workbook, return {session_id, company, years, sheets[], metrics[]}.
  • POST /api/fie/sessions/{id}/answer {query, audience?} → FIE Response. Look up the resident store — never call from_workbook on this path.
  • POST /api/fie/sessions/{id}/reload (multipart) → re-ingest + bust cache (after Save).
  • DELETE /api/fie/sessions/{id}; reuse assert_safe_upload on every upload.
  • Add the Electron origin to CORS_ALLOW_ORIGINS.
Deliverables
  • New session router + registry; tests (create/answer/reload/delete, no-reparse-on-answer, cache-bust).
Regression guard: a test must assert answer does not call from_workbook (parse only on create/reload). A 50-question chat = 1 ingest.
Accept when: upload an xlsx → get a session_id; 3 questions answer correctly with citations; edit+reload changes the answers; full suite green.
Feed me: “Phase 0 — backend session layer”.

1 Electron + React skeleton

FRONTENDPhase 0 §2 §3 §5 §7
Bootable shell: Electron spawns the Python sidecar, renderer waits for readiness, app frame renders.
Tasks
  • electron-vite + React + TypeScript; main / preload / renderer split.
  • Main spawns the FIE backend on a free port chosen at launch; kills it on before-quit.
  • Preload exposes typed window.api via contextBridge (contextIsolation:true, no nodeIntegration): file open/save dialogs, fs writes, backend port.
  • Splash → poll GET /readiness until 200 → mount app; error screen + log path on failure.
  • Tailwind + shadcn/ui; Zustand store skeleton (backend, session, workbook, panels, view, chat, jobs, toasts).
  • Left rail (Home · Sheet · PDF · Ask AI · Dashboard · Save) + empty Home with centered +.
Accept when: npm run dev launches; splash shows; backend becomes ready; left rail + empty Home render; closing the app kills the backend.
Feed me: “Phase 1 — Electron + React skeleton”.

FRONTENDPhase 1 §6.1 §6.2 §6.4 §6.5 §10
Open an Excel workbook end-to-end and edit it in an Excel-like grid.
Tasks

3 OCR / PDF extraction path

FRONTENDPhase 2 §6.2 §6.3 §6.6
Drop annual-report PDFs, watch extraction, review, and load the generated workbook.
Tasks
  • PDF route in the upload modal → POST /api/extraction/jobs (multipart) → poll GET /api/extraction/jobs/{id}.
  • Per-file list: name · size · progress bar · status; overall progress; Cancel; per-file error + retry.
  • Surface OCR confidence; flag low-confidence pages.

  • Validation overlay: tint cells by validation_status (CLEAN/MISMATCH/WITHHELD) + legend + toggle.
Accept when: drop 2 PDFs → per-file progress → Review → sheet loads with validation tints; a failed file can be retried.

7 Save, reload/cache-bust, recovery, polish

FRONTENDBACKENDPhases 2–6 §6.10 §8 §9 §11 §13
Persist edits everywhere consistently; guard data loss; finish the UX.
Tasks
  • Save semantics: OCR path → Save As (.xlsx + extracted .json); Excel path → overwrite original (Save As = copy). JSON travels with the xlsx.
  • On Save: produce xlsx bytes (Univer/SheetJS) → window.api writes to disk → POST /api/fie/sessions/{id}/reload (re-ingest + cache-bust) → clear dirty + “Saved” toast.
  • Unsaved-changes guard: intercept window close (before-quit), new-file open, view switches that drop edits.
  • Crash recovery: state.json in Electron userData (last path, autosave draft, window bounds).
  • Toasts (top-right) for info/warning/error; save bar (top); keyboard shortcuts (Ctrl+S/Z/Y/O); native menu (File/Edit/View/Help).
Accept when: edit → Save writes both files and Ask AI/Dashboard reflect the new numbers; closing with unsaved edits prompts; a crash recovers the draft.
Feed me: “Phase 7 — Save, reload, recovery, polish”.

8 Packaging + end-to-end integration

FRONTENDBACKENDPhases 0–7 §14 §15
Ship a single installable desktop app with the backend bundled — no Docker, no external services.
Tasks

  • First-run smoke: install → launch → open Excel → ask → dashboard → save, on a clean machine.

Accept when: the built installer runs the full flow on a machine without Python/Docker installed.
Feed me: “Phase 8 — Packaging + E2E”.
